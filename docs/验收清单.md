# 双机快传 LanLink — 两台真机验收清单

> 目标：在两台 Windows 10/11 电脑上验证局域网、网线直连、权限、还原和异常处理。  
> 建议准备：两台电脑、一根网线、一个路由器/交换机、一个 ≥1GB 的测试文件。

## 0. 验收前准备

- [ ] 两台电脑都复制了完整的 `LanLink` 文件夹。
- [ ] 两台电脑都能双击 `LanLink.cmd` 启动界面。
- [ ] 两台电脑的当前用户都在管理员组（或知道管理员密码）。
- [ ] 记录两台电脑的计算机名、网卡名、当前 IP 配置（`ipconfig /all`）。
- [ ] 临时关闭或放行 360/火绒等第三方防火墙的 SMB 拦截。
- [ ] 测试文件准备：1GB 左右的单个文件 + 一个含中文/空格的文件夹。

## 1. 局域网模式

### 1.1 主机启动共享

1. 两台电脑连同一个路由器/交换机/Wi-Fi。
2. PC-A 双击 `LanLink.cmd`，UAC 点“是”。
3. 共享目录保持默认，连接方式“自动识别”，点【启动共享】。

预期：

- [ ] 界面显示“共享中：LanLink | 192.168.x.x | 等待客户端...”。
- [ ] UAC 只弹一次（本次运行）。
- [ ] 日志无红色错误。
- [ ] `Get-SmbShare` 能看到 `LanLink`。
- [ ] `Get-NetFirewallRule -Group LanLink` 能看到 TCP 445、UDP 51234 两条规则。

### 1.2 客户端发现与连接

1. PC-B 双击 `LanLink.cmd`，切到“客户端”。
2. 点【搜索主机】。
3. 选中 PC-A，点【连接选中主机】。
4. PC-A 弹窗点【允许】。

预期：

- [ ] PC-B 列表出现 PC-A 的计算机名和 IP。
- [ ] PC-A 弹窗显示 PC-B 的计算机名和 IP，30 秒倒计时正常。
- [ ] PC-B 自动打开 `\\PC-A\LanLink`，并映射一个盘符（Z→E）。
- [ ] 资源管理器中能看到该盘符（不是只有 UNC 路径）。
- [ ] PC-A 的“已连接客户端”列表出现 PC-B。

### 1.3 文件传输

1. 从 PC-B 往映射盘复制 1GB 测试文件。
2. 从 PC-A 的共享目录读取该文件。
3. 复制含中文和空格的文件夹。

预期：

- [ ] 文件完整，大小/哈希一致。
- [ ] 中文/空格路径正常。
- [ ] 记录传输速度（可选：`robocopy` 统计）。
- [ ] PC-A 共享目录中出现文件。

### 1.4 只读共享

1. PC-A 停止共享并还原。
2. 勾选“只读共享”，重新启动共享。
3. PC-B 重新连接，尝试新建/删除文件。

预期：

- [ ] PC-B 可以读取。
- [ ] PC-B 新建/删除/重命名被拒绝（权限不足）。
- [ ] PC-A 本机仍可正常修改。

### 1.5 拒绝与超时

1. PC-B 发起连接。
2. PC-A 在弹窗点【拒绝】。

预期：

- [ ] PC-B 提示“主机拒绝连接”，不映射盘符。
- [ ] PC-A 日志记录拒绝。

再测试：PC-A 不操作弹窗，等待 30 秒。

- [ ] 弹窗自动关闭并拒绝。
- [ ] PC-B 提示等待超时。

### 1.6 历史电脑列表

1. PC-B 连接，PC-A 点【允许】。
2. PC-A 切到“历史电脑”页签。

预期：

- [ ] 历史列表出现 PC-B，默认**未勾选**“记住”。
- [ ] 显示电脑名、IP、最后连接时间、连接次数。
- [ ] 勾选 PC-B 的“记住”，PC-A 日志显示“已记住电脑 PC-B”。
- [ ] PC-B 断开后再连接，不再弹窗。
- [ ] 取消勾选后，PC-B 断开再连接，重新弹窗。
- [ ] 点 PC-B 行尾垃圾桶，确认删除后历史行消失。
- [ ] 删除后 PC-B 再连接，重新弹窗。
- [ ] 删除当前仍连接的 PC-B，当前连接不断开，历史行消失。

### 1.7 默认记住开关

1. PC-A 在历史列表保留一台未记住的旧电脑（例如取消勾选 PC-B）。
2. 打开“默认记住已连接电脑”。
3. 观察已有历史行。

预期：

- [ ] 打开/关闭开关时，已有历史行的勾选状态**不会立即变化**。
- [ ] PC-B 再次连接仍需 PC-A 允许；允许后 PC-B 行自动勾选，日志显示“已按默认设置记住”。
- [ ] PC-B 再断开重连，不再弹窗。
- [ ] 手动取消 PC-B 的勾选后，即使开关打开，PC-B 再连接仍弹窗。
- [ ] 关闭开关后，已勾选的 PC-A/PC-B 仍保持勾选和免确认。
- [ ] 新电脑在开关关闭时首次连接，历史行默认未勾选。

### 1.8 断开与还原

1. PC-B 点【断开连接】。
2. PC-A 点【停止共享并还原】。

预期：

- [ ] PC-B 盘符消失，UNC 路径不可再访问。
- [ ] PC-A 的 `LanLink` 共享被删除。
- [ ] PC-A 的 `LanLink` 防火墙规则被删除。
- [ ] PC-A 的 `LanLink` 本地账户被删除（或至少被禁用）。
- [ ] PC-A 的 IP 配置与验收前一致（DHCP 或原静态）。
- [ ] `%ProgramData%\LanLink\state.json` 被删除。

## 2. 网线直连模式

### 2.1 物理连接

1. 用网线直接连接 PC-A 和 PC-B 的以太网口。
2. 确认两端网卡灯亮、Windows 显示“未识别的网络”或类似状态。
3. 两台电脑的 Wi-Fi 可以保持连接。

### 2.2 主机配置

1. PC-A 选择“仅网线直连”，网卡选择以太网卡，点【启动共享】。

预期：

- [ ] PC-A 以太网卡获得 `192.168.77.1/24`（或 78.1/79.1）。
- [ ] 日志显示“主机直连地址：192.168.77.1/24”。
- [ ] 共享启动成功。
- [ ] 原 IP 配置已保存到 `%ProgramData%\LanLink\state.json`。

### 2.3 客户端配置与连接

1. PC-B 选择“仅网线直连”，网卡选择以太网卡，点【搜索主机】。

预期：

- [ ] PC-B 自动配置 `192.168.77.2/24`（或与主机同网段）。
- [ ] 搜索到 PC-A。
- [ ] PC-A 允许后，PC-B 映射成功并打开共享。
- [ ] 传输 1GB 文件成功。

### 2.4 网段冲突回退

1. 先让 PC-A 的 Wi-Fi 处于 `192.168.77.x` 网段（或手动占用 77 网段）。
2. 再启动直连共享。

预期：

- [ ] 工具跳过 77，使用 `192.168.78.1`。
- [ ] PC-B 依次尝试 77/78，最终在 78 网段发现主机并连接。

### 2.5 还原

1. PC-A 点【停止共享并还原】。
2. PC-B 点【还原网络配置】。

预期：

- [ ] 两台电脑的以太网卡恢复验收前的 DHCP/静态配置。
- [ ] `ipconfig` 中不再有 192.168.77/78/79 的残留地址。
- [ ] 拔掉网线后，Wi-Fi 网络不受影响。

## 3. 异常与恢复

### 3.1 强制结束 GUI

1. 主机共享运行中，用任务管理器结束 `powershell.exe`（LanLink GUI）。
2. 重新打开 `LanLink.cmd`。

预期：

- [ ] 启动时提示“检测到上次共享未正常还原”。
- [ ] 点“是”后，共享、防火墙、IP 均被还原。
- [ ] 点“否”后，工具仍可正常打开，但状态文件保留。

### 3.2 还原失败重试

1. 共享运行中，手动删除/占用共享目录，或制造还原失败条件。
2. 点【停止共享并还原】。

预期：

- [ ] 界面提示“还原失败，请重试”，停止按钮仍可用。
- [ ] 再次点击可以重试。
- [ ] 日志包含具体错误。

### 3.3 盘符冲突

1. 客户端先手动映射 Z、Y、X 等盘符。
2. 再连接 LanLink 共享。

预期：

- [ ] 工具自动选择下一个空闲盘符（如 W）。
- [ ] 不覆盖已有映射。

### 3.4 多网卡

1. 电脑同时有以太网、Wi-Fi、VPN/虚拟网卡。
2. 分别测试“自动识别”和手动选择网卡。

预期：

- [ ] 自动模式优先选择有网关的物理网卡。
- [ ] 直连模式优先选择以太网卡。
- [ ] 手动选择后，工具使用指定网卡。
- [ ] 不会误改 VPN/虚拟网卡。

### 3.5 刷新网卡

1. 打开工具，记录当前网卡下拉和客户端页“网卡摘要”。
2. 拔掉网线，或禁用/启用 Wi-Fi。
3. 点主机页或客户端页的【刷新网卡】。

预期：

- [ ] 下拉列表更新，新增/移除的网卡正确反映。
- [ ] 原网卡仍存在时保持选中；不存在时回退“自动选择”并写警告日志。
- [ ] 客户端页“网卡：XXX”摘要同步更新。
- [ ] 主机共享运行中点刷新，提示停止共享后才能刷新。
- [ ] 客户端搜索/连接中点刷新，提示稍后再试。

### 3.6 中文路径与空格

1. 共享目录设为 `D:\共享 文件\测试`。
2. 客户端连接并复制文件。

预期：

- [ ] 共享创建成功。
- [ ] 客户端可以访问、复制。
- [ ] 日志和界面中文正常，无乱码。

### 3.7 Windows 11 24H2 / 家庭版

- [ ] 主机为 Windows 11 24H2 时，客户端可以登录（非 Guest）。
- [ ] 家庭版主机可以创建共享。
- [ ] 家庭版客户端可以映射盘符。
- [ ] 没有出现“不允许来宾访问”的错误。

## 4. CLI 验收（可选）

```powershell
# 主机（管理员 PowerShell）
.\LanLink.ps1 -Role Host -NoGui -SharePath D:\Share -AutoApprove

# 客户端（另开窗口）
.\LanLink.ps1 -Role Client -NoGui -HostAddress 192.168.77.1

# 状态
.\LanLink.ps1 -Role Status -NoGui -Json

# 还原
.\LanLink.ps1 -Role Restore -NoGui
```

预期：

- [ ] CLI 主机启动后打印共享信息，客户端能连接。
- [ ] `Ctrl+C` 后主机自动停止并还原。
- [ ] `Status -Json` 输出合法 JSON。
- [ ] `Restore` 返回 0；若状态保留则返回 1。
