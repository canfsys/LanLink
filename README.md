# 双机快传 LanLink

[![CI](https://github.com/canfsys/LanLink/actions/workflows/ci.yml/badge.svg)](https://github.com/canfsys/LanLink/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

一个面向 Windows 10/11 的双机文件互传小工具：把同一个文件夹复制到两台电脑，各自双击运行，主机点“共享”，客户端点“连接”，工具会自动完成网络配置、SMB 共享创建和盘符映射。

适合两种场景：

- **局域网**：两台电脑连同一个路由器/交换机/Wi-Fi。
- **网线直连**：一根网线直接连接两台电脑（现代网卡支持自动翻转，普通网线即可）。

> 设计目标：不需要记 IP、不需要手写共享命令、不需要在客户端输入密码。首次连接由主机弹窗确认，之后可勾选“记住”免确认。

---

## 1. 系统要求

- 两台电脑均为 **Windows 10 / Windows 11**（家庭版、专业版都可以）。
- Windows PowerShell 5.1（系统自带，无需安装）。
- 主机和“网线直连”的客户端需要 **管理员权限**（会弹 UAC）。
- 两台电脑在同一个局域网/同一根网线，且没有启用客户端隔离（AP Isolation）。
- 建议关闭或放行第三方安全软件的 SMB/445 端口拦截。

## 3. 快速开始

### 3.1 复制工具

把 `LanLink` 文件夹通过 U 盘、网盘或已有的网络方式复制到两台电脑。建议放在同一路径，例如：

```
D:\LanLink\
```

### 3.2 主机（共享方）

1. 双击 `LanLink.cmd`。
2. 在 UAC 窗口点“是”（创建共享、防火墙规则、直连 IP 需要管理员权限）。
3. 选择共享文件夹（默认 `C:\Users\Public\LanLinkShare`，不存在会自动创建）。
4. 连接方式保持“自动识别”即可；如果是网线直连，也可以选“仅网线直连”。
5. 点击 **【启动共享】**。
6. 界面显示“等待客户端连接”后，让另一台电脑操作。

> 主机可以最小化窗口，但**不要关闭**，否则共享会停止（关闭时会询问是否还原）。

### 3.3 客户端（访问方）

1. 双击 `LanLink.cmd`。
2. 点 **【② 作为客户端：连接主机】**。
3. 点 **【搜索主机】**。
4. 在列表里选中主机，点 **【连接选中主机】**。
5. 主机端会弹出“有电脑请求连接”，点 **【允许】**。
6. 客户端自动映射网络盘并打开共享文件夹。

也可以不搜索，直接在“手动 IP”里输入主机 IP，再点 **【连接此 IP】**。

### 3.4 之后再用

- 主机点【启动共享】，客户端点【搜索主机】→【连接】即可。
- 主机面板下方有 **“已连接”** 和 **“历史电脑”** 两个页签：
  - 历史电脑会记录所有被允许连接过的客户端（电脑名、IP、最后连接时间、次数）。
  - 勾选某行的“记住”，该电脑下次连接自动放行；取消勾选后恢复弹窗。
  - 点行尾垃圾桶可删除该电脑的历史记录，下次连接需要重新确认。
- **默认记住已连接电脑** 开关：
  - 只影响**之后发生的新连接**，不会立即修改已有历史行。
  - 打开后，新电脑或历史中未记住的旧电脑在“允许”后会自动勾选“记住”，之后免确认。
  - 关闭不会清除已有记住状态；手动勾选/取消过的电脑优先。
- 网卡列表可能因插拔网线/Wi-Fi 变化，点【刷新网卡】可重新扫描，原选择会尽量保留。

## 4. 两种连接方式

### 4.1 局域网（路由器/交换机/Wi-Fi）

两台电脑都连到同一个路由器或交换机，主机使用现有 DHCP 地址，客户端也使用现有地址。工具只负责：

- 创建共享；
- 放行 TCP 445 和 UDP 51234；
- 发现主机并映射盘符。

如果局域网开启了“AP 隔离/客户端隔离”，两台电脑无法互相访问，需要在路由器里关闭该功能。

### 4.2 网线直连

1. 用网线直接连接两台电脑（普通网线即可，网卡一般支持自动 MDI/MDIX）。
2. 两台都运行工具，主机先点【启动共享】。
3. 客户端选择“自动识别”或“仅网线直连”，点【搜索主机】。

工具会自动：

- 主机配置 `192.168.77.1/24`；
- 客户端配置 `192.168.77.2/24`；
- 如果 77 网段被占用，自动尝试 `192.168.78.x`、`192.168.79.x`；
- 停止共享时恢复原来的 DHCP/静态 IP 配置。

> 直连时两台电脑的 Wi-Fi 可以保持连接，工具只会改动你选中的**以太网卡**。

## 5. 界面说明

### 主机页

| 控件 | 说明 |
|---|---|
| 共享文件夹 | 要共享的目录，默认 `C:\Users\Public\LanLinkShare` |
| 连接方式 | 自动识别 / 仅局域网 / 仅网线直连 |
| 网卡 | 自动选择，或手动指定（多网卡时建议手动确认）；点【刷新网卡】重新扫描 |
| 只读共享 | 勾选后客户端只能读取，不能修改/删除 |
| 默认记住已连接电脑 | 只影响之后连接；打开后新电脑/未记住的旧电脑允许后自动勾选；不会立即修改已有行 |
| 启动共享 | 创建账户、共享、防火墙规则，开始等待连接 |
| 停止共享并还原 | 删除共享/防火墙规则，恢复网卡 IP |
| 已连接 | 显示当前已允许的电脑名、IP、连接时间 |
| 历史电脑 | 所有连接过的电脑；行内勾选“记住”，垃圾桶删除历史 |

### 客户端页

| 控件 | 说明 |
|---|---|
| 搜索主机 | 在局域网/直连网段广播发现主机 |
| 手动 IP | 搜索不到时直接输入主机 IP |
| 连接选中主机 | 向主机发起连接请求，等待主机允许 |
| 断开连接 | 删除本次映射的盘符 |
| 还原网络配置 | 如果做过直连静态 IP，点此恢复原配置 |
| 网卡摘要 / 刷新网卡 | 显示当前使用的网卡；点刷新重新扫描 |

## 6. 命令行用法

工具同时提供 CLI，便于排查和自动化。需要管理员权限的操作仍会弹 UAC。

```powershell
# 查看状态（JSON）
.\LanLink.ps1 -Role Status -NoGui -Json

# 还原上次未还原的配置
.\LanLink.ps1 -Role Restore -NoGui

# 主机（无人值守，必须显式加 -AutoApprove）
.\LanLink.ps1 -Role Host -NoGui -SharePath D:\Share -AutoApprove

# CLI 主机：新客户端首次允许后默认勾选“记住”
.\LanLink.ps1 -Role Host -NoGui -SharePath D:\Share -AutoApprove -RememberClients

# 客户端：指定主机 IP
.\LanLink.ps1 -Role Client -NoGui -HostAddress 192.168.77.1

# 客户端：自动发现
.\LanLink.ps1 -Role Client -NoGui
```

`-Role Host` 会持续运行，按 `Ctrl+C` 停止并还原。

`-RememberClients` 等价于 CLI 主机启动时打开“默认记住已连接电脑”，只影响之后记录的客户端。

> CLI 主机模式会**自动允许**所有连接，只建议在可信环境使用。

## 7. 常见问题

### 7.1 双击没反应 / 提示“需要管理员权限”

- 主机和直连客户端需要 UAC 提权，请在弹窗点“是”。
- 如果 UAC 被取消，重新点【启动共享】即可再次弹出。
- 请双击 `LanLink.cmd`，不要直接右键 `LanLink.ps1` 运行（可能被执行策略拦截）。
- 如果 Windows SmartScreen 提示“已保护你的电脑”，点“更多信息”→“仍要运行”即可（脚本未做数字签名）。

### 7.2 客户端提示“无法连接 445 端口”

按顺序检查：

1. 主机是否已点【启动共享】，界面是否显示“等待客户端连接”。
2. 两台电脑是否在同一网段（`ipconfig` 查看 IPv4）。
3. 主机 Windows 防火墙是否放行了 TCP 445；工具会自动加规则，但 360/火绒等第三方防火墙可能仍拦截。
4. 主机是否开启了“网络发现/文件共享”相关服务（工具会启动 `LanmanServer`）。
5. 路由器是否开启了 AP 隔离。

### 7.3 客户端搜不到主机

- 确认主机已启动共享，且主机窗口**一直保持“共享中”**，不要在客户端搜索前点【停止共享并还原】。
- 直连场景确认网线插好、网卡灯亮，客户端选择的是**以太网卡**。
- 检查 UDP 51234 是否被防火墙拦截。v1.0.1 起发现规则允许任意地址，并会同时向 `192.168.x.1` 单播 + 子网广播发送发现请求。
- 看客户端日志：应出现“本机绑定 192.168.x.2，发现目标：192.168.x.1, ...”。  
  看主机日志：应出现“UDP 发现服务已就绪”和“收到发现请求：192.168.x.2”。  
  如果主机完全没有“收到发现请求”，优先检查主机防火墙/第三方安全软件是否拦截 UDP 51234。
- 如果客户端日志出现 `绑定 192.168.x.2 失败：...请求的地址无效`，说明静态 IP 还处于 DAD（地址冲突检测）的 `Tentative` 状态。v1.0.1 及以前会回退到 `0.0.0.0`，发现包从 Wi-Fi 发出，直连主机收不到；请升级到 **v1.0.2**，它会等地址 `Preferred` 后再搜索。
- 可以直接在“手动 IP”里输入主机 IP 尝试连接。

### 7.4 映射成功但资源管理器里看不到盘符

- **不要**右键“以管理员身份运行” `LanLink.cmd`。提权进程创建的映射盘，普通资源管理器可能看不到。
- 正确做法：普通双击 `LanLink.cmd`，工具会在需要时单独弹 UAC 提权。
- 也可以直接在资源管理器地址栏输入 `\\主机IP\LanLink`。

### 7.5 直连后“未识别的网络”

工具已经把防火墙规则应用到所有网络配置文件（域/专用/公用），不依赖“网络位置”设置成功。只要 IP 配好、445 放行，通常不影响连接。

### 7.6 停止共享后 IP 没恢复

- 重新打开工具，若检测到上次未还原，会提示还原。
- 或运行：`.\LanLink.ps1 -Role Restore -NoGui`。
- 仍失败时，用管理员 PowerShell 手动执行下面的“手动还原”。

### 7.7 大文件复制失败

- 共享目录所在磁盘必须是 **NTFS**；FAT32 单文件不能超过 4GB。
- 目标磁盘空间不足、文件被占用也会失败。
- 建议用资源管理器直接复制，或 `robocopy`。

### 7.8 Windows 家庭版可以用吗？

可以。工具只使用标准的 SMB2/3 共享和客户端映射，不依赖域、组策略或 Hyper-V。

### 7.9 安全吗？

- 共享账户 `LanLink` 的密码每次会话随机生成，只保存在内存中，不写入磁盘。
- 客户端必须经过主机弹窗允许（或已勾选“记住”）。
- 凭据在局域网内通过 UDP 明文传输，**仅适用于可信家庭/办公室局域网**，不要在公共 Wi-Fi 使用。
- 建议只在需要时启动共享，用完点【停止共享并还原】。
- 可以勾选“只读共享”降低误删风险。

### 7.10 客户端已断开，主机还提示“有一台电脑正在连接”

v1.0.3 起：

- 客户端点【断开连接】时会通过 UDP 主动通知主机，主机列表立即移除该电脑。
- 主机点【停止共享并还原】时还会查询真实 SMB 会话（`Get-SmbSession`），只有在确实有打开文件/活跃会话时才提示。
- 如果仍看到旧提示，直接点“是”继续即可；或重启双方工具清空界面列表。

### 7.11 历史电脑 / 默认记住

- “历史电脑”只记录**被允许连接过**的客户端；被拒绝的不会出现。
- “默认记住已连接电脑”只影响之后发生的连接，不会在拨动开关时立即修改已有行。
- 未记住的电脑（无论新电脑还是历史电脑）第一次连接仍会弹窗；允许后才会自动勾选。
- 手动勾选/取消某台电脑后，该电脑的手动选择优先；全局开关不会覆盖。
- 旧版 `allowed-clients.json` 中已记住的电脑会自动迁移为勾选状态。
- 删除历史记录不会断开当前正在连接的会话，只影响下次连接是否需要确认。

## 8. 手动还原（兜底）

如果工具异常退出且自动还原失败，用**管理员 PowerShell**执行：

```powershell
# 1. 查看当前网卡和共享
Get-NetIPConfiguration
Get-SmbShare

# 2. 恢复 DHCP（把“以太网”换成你的网卡名）
Set-NetIPInterface -InterfaceAlias "以太网" -AddressFamily IPv4 -Dhcp Enabled
ipconfig /renew

# 3. 删除共享
Remove-SmbShare -Name LanLink -Force

# 4. 删除防火墙规则
Remove-NetFirewallRule -Group LanLink

# 5. 删除临时账户
Remove-LocalUser -Name LanLink
```

如果原来是静态 IP，请用 `New-NetIPAddress` 按原 IP/掩码/网关重新配置。

## 9. 卸载 / 清理

1. 点【停止共享并还原】。
2. 删除 `LanLink` 文件夹。
3. 如需清理残留：
   - `C:\ProgramData\LanLink`（状态和 Helper 日志）
   - `%LOCALAPPDATA%\LanLink`（设置、客户端 ID、历史电脑记录、GUI 日志）
4. 确认共享、防火墙规则、`LanLink` 账户已删除（见上一节）。

## 10. 版本

- v1.0.0：局域网/网线直连、主机确认、记住客户端、只读共享、盘符映射、停止还原、CLI、崩溃恢复提示。
- v1.0.1：修复直连发现——子网广播地址构造失败导致只发 `255.255.255.255`（常从 Wi-Fi 默认网卡发出，直连以太网收不到）；改为正确的 `192.168.x.255` 子网广播 + 向 `192.168.x.1` 单播 + 3 轮重试；UDP 51234 防火墙规则允许任意地址；增加主机/客户端发现诊断日志；主机端拒绝 APIPA（169.254）局域网地址。
- v1.0.2：修复静态 IP 刚配置时处于 DAD `Tentative` 状态导致 `UdpClient.Bind` 失败（日志“请求的地址无效”）；Helper 现在等到地址 `Preferred` 才返回，客户端绑定增加最多 3 秒重试。
- v1.0.3：客户端断开时主动通知主机；主机“停止共享”时查询真实 SMB 会话，避免客户端已断开仍提示“有一台电脑正在连接”。
- v1.1.0：新增网卡刷新（主机/客户端）、历史电脑列表（记住勾选 + 垃圾桶删除）、默认记住已连接电脑开关；旧授权记录自动迁移。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/Test-LanLink.ps1
```

自检只做语法检查、Helper 自检、发现协议回环测试和本地 IPC，不修改网卡/共享/防火墙。测试数据默认写入仓库内的 `.testdata`、`.teststate`（已被忽略）；如果目录只读，可以指定临时目录：

```powershell
$env:LANLINK_TEST_DATA_DIR  = "$env:TEMP\LanLinkData"
$env:LANLINK_TEST_STATE_DIR = "$env:TEMP\LanLinkState"
```

### 文件编码约定

`.ps1` / `.cmd` 使用 **UTF-8 BOM + CRLF**，Windows PowerShell 5.1 依赖 BOM 正确显示中文。`.gitattributes` 已将脚本按二进制处理，避免换行符或编码转换破坏文件，请保持原样提交。
